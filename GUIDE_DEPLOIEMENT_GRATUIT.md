## 🚀 2. Solution Recommandée N°1 : VERCEL (0 DA / À Vie)
*Sous-domaine obtenu : `productsglobaldz.vercel.app`*

### Depuis votre Téléphone Android ou Ordinateur :
1. **Créer un compte GitHub gratuit :**
   - Allez sur [github.com](https://github.com) et créez un compte gratuit si vous n'en avez pas.
   - Créez un nouveau dépôt appelé `products-global-dz`.
   - Déposez-y les fichiers de votre projet (le fichier `vercel.json` est déjà configuré dans le projet).

2. **Connecter Vercel :**
   - Allez sur [vercel.com](https://vercel.com) et appuyez sur **"Sign Up"** (ou Log in) avec votre compte GitHub.
   - Sur votre tableau de bord, cliquez sur **"Add New Project"**.
   - Choisissez votre dépôt `products-global-dz`.
   - Vercel détecte automatiquement le projet **Vite**.
   - Dans le champ "Project Name", tapez : `productsglobaldz`.
   - Cliquez sur le bouton bleu **"Deploy"**.

3. **Résultat en 45 secondes :**
   - Vercel compile votre site et vous attribue votre lien officiel gratuit avec certificat de sécurité SSL :
     `https://productsglobaldz.vercel.app`

## ⚡ 3. Solution Alternative N°2 : NETLIFY (0 DA / À Vie)
*Sous-domaine obtenu : `productsglobaldz.netlify.app`*

1. Créez un compte sur [netlify.com](https://netlify.com).
2. Connectez votre compte GitHub et choisissez le projet.
3. Le fichier `netlify.toml` inclus dans le projet configure automatiquement la compilation `npm run build` et le dossier `dist`.
4. Dans **Site Settings > Domain management**, vous pouvez renommer le sous-domaine pour obtenir :
   `https://productsglobaldz.netlify.app`
